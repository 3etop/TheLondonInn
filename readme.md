# TheLondonInn

Sitio web del menú de The London Inn, listo para publicarse con GitHub Pages.

## Archivos

- `index.html`: página del menú y contacto.
- `styles.css`: diseño responsive.
- `scripts.js`: filtros, carruseles, calificaciones y modales.
- `crs/`: imágenes de productos, fondos, logos y favicons.

## Publicación

Configura GitHub Pages para publicar desde la rama `main` y la carpeta raíz `/`. No requiere compilación ni instalación de dependencias.
